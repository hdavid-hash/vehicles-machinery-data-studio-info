# Vehicles & Machinery Data Studio

Vehicles & Machinery Data Studio is a project for structured acquisition, provenance tracking, extraction and interpretation of machinery data from public and authorized sources.

The system is designed to use bounded, policy-controlled acquisition with explicit access permissions, rate limiting, provenance, snapshots and hashes.

AI is not the primary web acquisition mechanism. AI may be used as an explicitly approved fallback and for interpretation and structuring of retrieved source data.

Automated requests are intended to:

- use documented and permitted access paths;
- respect technical restrictions and rate limits;
- avoid authentication, paywall, CAPTCHA or anti-bot circumvention;
- remain narrowly scoped and auditable;
- identify the application honestly when required by the source.

Project contact and maintenance information is provided through this repository.
